## 🛠️ COMMON TASKS

### Starting the Server
```bash
cd "c:\Users\Student\Documents\Melanin Son"
node server.js
```

### Customizing Colors
Edit `:root` in `assets/css/style.css`:
```css
--primary-color: #D4AF37;      /* Change to your color */
--secondary-color: #1a1a1a;
--accent-color: #8B4513;
```

### Adding a Page
1. Create new HTML file in `pages/` directory
2. Copy structure from existing page
3. Update navigation links on all pages
4. Add CSS styles as needed
5. Test responsiveness

### Adding Products
Edit `pages/shop.html`:
```html
<div class="product-card card">
    <img src="../assets/images/product.jpg" alt="Product">
    <h3>Product Name</h3>
    <p class="product-price" data-price="99.99">$99.99</p>
    <button class="btn">Add to Cart</button>
</div>
```

### Deploying to Production
1. Minify CSS and JavaScript
2. Optimize images for web
3. Set up HTTPS/SSL
4. Configure server security
5. Enable GZIP compression
6. Set up analytics
7. Create sitemap.xml
8. Submit to search engines
