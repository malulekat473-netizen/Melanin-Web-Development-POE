## 🔤 TYPOGRAPHY STYLES

### Headings
- **H1:** 48px Georgia (hero/pages)
- **H2:** 32px Georgia (sections)
- **H3:** 24px Georgia (subsections)
- **H4:** 18px Georgia (cards)

### Body Text
- **Paragraphs:** 16px Segoe UI
- **Small text:** 14px Segoe UI
- **Line height:** 1.6 (very readable)

### Links
- **Color:** Gold (#D4AF37)
- **Hover:** Brown (#8B4513)
- **Underline on hover:** Yes
- **Outline on focus:** 2px Gold

## ⌨️ INTERACTIVE ELEMENTS

### Buttons
```
Normal: [Button Text]
Hover:  [Button Text] ↑ Lifted, Shadow
Focus:  [Button Text] ✦ Gold outline
Active: [Button Text] ◆ Pressed
```

### Navigation Links
```
Normal:  Home   About   Shop   Donate   Contact
Hover:   Gold underline expands →
Active:  Gold text, bold, highlighted
Focus:   Gold outline, underline
```

### Form Inputs
```
Default: ┌─────────────┐
         │ Placeholder │
         └─────────────┘

Focus:   ┌─────────────┐
         │ Cursor here │ ← Gold border
         └─────────────┘

Error:   ┌─────────────┐
         │ Invalid     │ ← Red border
         └─────────────┘
```
